# شجرة علي — ALI-NEW

**ALI-NEW** مشروع قيد البناء لمنصة فيديو متعددة اللغات. يحتوي المستودع حالياً على نموذج تحكم وفهرسة وأدوات تحقق؛ وجود الواجهة لا يعني أن منصة الفيديو أو وظائفها الخلفية مكتملة.

**الحالة الهندسية:** A0 = YELLOW. لا تُعد المرحلة مغلقة، وA1 ما زالت مسودة غير معتمدة.

## ابدأ من هنا

1. **[نقطة التوقف وخطة البناء الرسمية](PROJECT-BUILD-TREE.md)** — المصدر الوحيد لترتيب المراحل A0–A12، وشروط القبول، وحالة العمل الحالية.
2. **[قواعد العمل والحوكمة](ALI-ALEX-MASTER-PROJECT-PROMPT.md)** — صلاحيات التنفيذ، والموافقات، والسلامة، والاختبار.
3. **[سجل الأفكار والقرارات والأسئلة المفتوحة](IDEAS-ALI-ALEX.md)** — القرارات المثبتة منفصلة عن المقترحات وما يحتاج قراراً.
4. **[دراسة معمارية CORE](CORE-BRAIN-ARCHITECTURE-STUDY.md)** — اتجاه معماري مقترح وحدود ما نُفذ فعلياً.
5. **[تعريف المنتج A1](docs/product/ALI-NEW-A1-PRODUCT-DEFINITION.md)** — مسودة PLANNED؛ لا تُعد معتمدة ولا تسمح ببدء A1.
6. **[خريطة الشاشات](docs/design/VIDEO-PLATFORM-SCREEN-MAP.md)** و[خط أساس التصميم](docs/design/ALI-NEW-APPROVED-DESIGN-BASELINE-2026-10-16.md).
7. **[شجرة علي التفاعلية](index.html)** — واجهة فهرسة للمراحل والملفات، وليست لوحة تحكم حية متصلة بكل خدمات GitHub.
8. **[package.json](package.json)** و[playwright.config.ts](playwright.config.ts) — أوامر الاختبار وإعداداته.

## قواعد مختصرة

- ترتيب المراحل الهندسية الحالية A0–A12 محكوم في PROJECT-BUILD-TREE.md. لا تبدأ مرحلة لاحقة قبل قبول الحالية وتوثيق الأدلة.
- تسلسل A/B/C فهرسة منطقية فقط؛ لا يغيّر أسماء الملفات أو مساراتها. يجب أن تطابق السجلات شجرة Git الفعلية.
- فرّق بين PLANNED وYELLOW وORANGE وGREEN. لا تُستخدم GREEN إلا لنطاق اجتاز معايير قبول محددة على commit معلوم.
- القراءة فقط هي الوضع الافتراضي. لا حذف أو دمج أو نشر أو تغيير حماية/صلاحيات/استضافة أو تفعيل مدفوع دون الموافقة المطلوبة.
- لا تُعامل الأفكار أو المسودات أو دراسة المعمارية كقرارات معتمدة. وثّق القرار المعتمد في المرجع المناسب وحدّث نقطة التوقف.

## نقطة العمل الحالية

راجع قسم Current checkpoint في PROJECT-BUILD-TREE.md قبل أي تنفيذ. تبقى هذه الصفحة مدخلاً مختصراً؛ لا تكرر تفاصيل المراحل أو سجل الجلسات.

## حدود المستودع

العمل هنا يخص AligasSRM/ALI-NEW فقط. لا تنقل مواد من مستودعات أخرى، ولا تغيّر الملفات أو الإعدادات خارج النطاق الموافق عليه. لا دمج ولا إغلاق A0 لمجرد نجاح الاختبارات الآلية؛ القبول البصري اليدوي ومراجعة الوصولية ومتابعة ملاحظات رؤوس الأمان تبقى بوابات مستقلة.
