CORE Incident Router

أدخل رقم تشغيل GitHub Actions أو مسارات الملفات المتغيرة. سيبحث النظام عن تطابق حرفي مع سجل هرمي مفتوح A/B/C وما بعده؛ إذا لم تكفِ الأدلة، سيعيد UNKNOWN ولن يخمّن.

1. إدخال الحادثة

عند إدخال رقم تشغيل، تُقرأ بيانات التشغيل والـ commit وملفات التغيير من GitHub العام. لا يتم استخدام token أو أي سر. مسارات التغيير قرينة ربط، وليست إثباتاً لسبب الفشل.

2. نتيجة التوجيه

بانتظار إدخال الأدلة. لم يتم تنفيذ أي تغيير على المستودع.

حدود الأمان

  • القراءة فقط؛ لا تعديل ملفات ولا إعادة تشغيل workflow ولا إنشاء PR.
  • الـ API محصور بالمستودع العام AligasSRM/ALI-NEW ورقم تشغيل رقمي.
  • التوجيه يحتاج تطابقاً دقيقاً بين مسار المورد بأي مستوى والـ registry؛ النصوص والكلمات المفتاحية وحدها لا تكفي.
  • التطابق لا يثبت السبب الجذري. إذا غاب المسار أو تعددت الاحتمالات، تبقى الحالة UNKNOWN وتحتاج تشخيصاً موجهاً.
